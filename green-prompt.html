Installation

Add AMUX Green Prompt to your project in a few simple steps.

  1. Step 1 Install the package

    Install AMUX Green Prompt using npm or your preferred package manager. 

    npm install amux-green-prompt
  2. Step 2 Import and call the optimizer

    Import the optimizer function and wrap your existing prompt before sending it to your AI model. 

    import { optimizePrompt } from "amux-green-prompt";

const result = await optimizePrompt(userPrompt);

console.log(result.optimized_prompt); // Use this with your AI model
  3. Step 3 Send optimized prompts

    Use result.optimized_prompt as the final request to your AI provider to reduce tokens and improve consistency.

    4. Before vs after

    Before:
Hello, could you please explain Java in detail? Thank you so much!

After:
Explain Java.

    The optimized prompt keeps intent but removes unnecessary tokens — saving cost, time, and resources while keeping responses focused.

FAQ

Does it send prompts to AMUX?

No. Optimization is local. Only anonymous aggregate metrics are transmitted.

Can I use it commercially?

Yes. AMUX Green Prompt is designed for production workloads and commercial use.
